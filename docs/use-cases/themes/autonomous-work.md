# Autonomous work

A user delegates progress toward an outcome while retaining clear scope, authority,
resource limits, and completion criteria. Agents can organize and adapt the work, but
accepted results, ownership, pending effects, and verification remain inspectable.

[UC-1: Adaptive autonomous delivery](../adaptive-autonomous-delivery.md) applies this theme
to a coordinator and continuing workers, with optional recurring supervision.
