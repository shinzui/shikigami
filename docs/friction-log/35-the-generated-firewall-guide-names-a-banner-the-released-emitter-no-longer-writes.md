# The generated firewall guide names a banner the released emitter no longer writes

## Attempted

Implement the architecture/generated ownership style gate against a fresh strict Keiro 0.22 scaffold.

## Encountered

The guide requires a fixed unversioned banner, while the released emitter writes a versioned language/node banner; checking the literal rejects all 64 legitimate generated modules.

```text
Guide: -- @generated by keiro-dsl; do not edit. Regenerated from the .keiro spec.
Released output: -- @generated by keiro-dsl 0.22.0.0 (language keiro-dsl 6) from aggregate ExecutionLifecycle; do not edit.
```

## Workaround

Recognize the exact selected 0.22 versioned owner banner only within generated paths and retain idempotent scaffold/conformance as the authoritative ownership check. Do not rewrite generated headers.
