Contract
ExecutionRootId, AttemptId and AllocationId use private KindID-backed UUIDv7 domains with full singular prefixes. Prefix, canonical encoding and UUID version/variant are checked; replay imposes no current-clock condition. Actual dispatch producers allocate in IO. SQL, evidence, RPC and cryptographic-preimage adapters render explicitly. Syntactically valid IDs do not authorize a request, replace ownership or refund allowance.
Native-run admission binds resolved creator, agent and immutable envelope to the opaque native workflow coordinate in the new root origin table. Receipt-first insertion arbitrates concurrency; the deferred FK requires root publication at commit. Origin/root failures condemn the transaction, concurrent losers publish no unused root, retries recover one entity, and changed bindings/supplied references refuse. Origins outlive native journal collection. Descendants still inherit one root and cannot create replacement allowance. Explicit low-level accounting APIs accept allocated IDs; no resource policy or process-tool activation is added.
Delegation's stored root reference restores to the checked type with a captured corruption result. Root-first accounting, immutable envelopes, finite suballocations, fencing, irreversible cancellation and settlement remain authoritative. Logical OperationId coordinate construction and other decoder owners remain open census work.
Operator root arguments refine before configuration IO. Fixture selectors use explicit synthetic fixed-timestamp UUIDv7 data and checked parsers; they are test data, not application allocators.
