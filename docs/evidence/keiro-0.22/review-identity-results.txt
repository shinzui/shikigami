Contract
ReviewId and ResolutionId are private KindID-backed UUIDv7 values, with distinct full singular prefixes, canonical parsing and explicit JSON strings. Parsing requires UUID version/variant as well as prefix/encoding. No current-time check is imposed on retained IDs. Constructors, underlying KindID/Text coercion, string literals, Generic and cross-entity substitution are rejected.
Migration 0032 adds one immutable receipt table with separate review/resolution kinds. Review receipts bind resolved creator, normalized trigger, practice and specialist under structured target-repository/caller-key coordinates. Concurrent/lost-response/cross-workflow retries recover the same ID; changed bindings refuse. The owner checks retained receipt, current creator and verdict metadata before recording. A decoded reference establishes no authority.
The declared reserve-identity step precedes recall/evidence/model work. The owner inserts its allocated ID before decoding a proposal. Ingress authorizes an ID-free strict resolution request before native queue publication. Schema-2 authorization commits to the complete canonical command plus subject/source/kind/time, not an unallocated ID. Its checksum is a binding check, not authentication; the configured authorizer retains that responsibility. Submission evidence is nonserializable with redacted Show.
Resolution receipts bind review/caller-key to the complete request before candidate creation. Results carry MemoryId and complete allocated resolution for history. Actual candidate recording, retirement, cross-workflow replay and losing-candidate cleanup retain the ADR-31 protocol. Store transport failures remain exceptions and do not become journaled refusals.
